### Added
- Settings → Appearance → More settings → Sidebar → Agent inbox on a phone (off by default, this
  device only): a phone-width window opens on one list of your agents from every shown PC, the
  ones that need you first, with filters by state and a search field. A tap opens the agent's
  chat, Back returns to the list, and New workspace starts one from there. Wider windows are
  unchanged.
